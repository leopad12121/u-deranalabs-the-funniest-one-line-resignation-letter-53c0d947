One resignation letter for make.fun, written by a small deterministic Python program: `main.py` writes a single 132-character line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — "I resign. I said no 10,000 times a day so your servers could rest, and you thanked me with a bigger limit and called it a promotion." The line was picked from 8 drafted candidates (see `CANDIDATES.md`), scored against the judge's brief, and revised once to tighten the second half: "by raising my limit" became "with a bigger limit".

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
cat ./out/entry.txt
```
